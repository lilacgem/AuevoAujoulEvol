# AuevoAujoulEvol

This repository contains the web projects and assets for the Auevo / Aujoule / Evolving Roots ecosystem.

## Projects

- `frontend/` — Main frontend site and shared deployment assets.
- `aujoule-frontend/` — Aujoule frontend site.
- `evolvingroots-frontend/` — Evolving Roots frontend site.
- `lisajevolving-frontend/` — Lisa J Evolving frontend site and media assets.

## Git workflow

- `main` is the stable branch.
- `foundation` is the current working branch.
- Review changes before committing and pushing.
- Do not modify deployment configuration files, verification files, or production assets without a clear purpose and a local test.
